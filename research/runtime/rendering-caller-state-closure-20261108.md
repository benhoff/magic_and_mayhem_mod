## Production boundaries

`tools/native_only_contract.py` names ten staged DLLs. Required boundaries include
the owned surface facade and its original callers; World whole-entry producer
bypasses; the glyph shared entry; panel, image/effect, minimap, colour and raster
interior splices; original screen/cursor orchestration and Qt presentation.
Retained original preparation is a supplier, with its actual side effects still
required. The complete cell producer is separately opt-in.

The caller-state acceptance contract links C01, C03, C07 and C09. It does not
require recursively replacing simulation. Conversely, pixels, low AX or a
successful normal session cannot alone establish required caller state.

## Whole-entry World WORD correction

The previous World callback changes only saved EAX. The selected original WORD
bodies also rewrite X/Y arguments, update their 16-word scratch workspace,
produce final XOR-zero arithmetic flags and clear x87 C1 for positive dimensions.
`world_word_state.h` prepares those effects without mutating published state,
then commits after the native command is accepted. Zero dimensions preserve the
original empty-frame argument and floating-state behavior. Unsupported positive
unmasked/reserved x87 controls and an occupied push slot refuse admission.
The canonical wire's palette word is restored after making the private state
model view; guest source bytes are not changed.

[The current comparison](caller-state-results-20261108/world-word-01.json) passes
12,744 unchanged-original/native cases through actual shared production tags22/36
entry assembly. It compares all GPRs/ESP, argument rewrites, workspace, defined
return flags, x87 control/status/three active values, nonzero XMM/MXCSR, complete
guarded destination and source preservation. The twelve precision/rounding modes
cover clipped, hidden, edge and empty inputs with padded/varied alignment.

The negative control reconstructs the former EAX-only publication policy using
the same actual entry assembly and native pixel provider. All 12,744 pixel
results agree, but zero complete caller-state results agree: workspace and flags
fail throughout; 12,672 argument comparisons and 6,336 x87 status comparisons
also differ. This is a controlled policy diagnostic, not execution of an old
installed DLL. The full current scene DLL also links successfully with the new
state-model dependency.

[The sanitized policy controls](caller-state-results-20261108/word-policy-01.json)

This private comparison supplies an owned CPU-plane pixel provider. It does not

## Caller requirements and remaining work

[The initial requirements analysis](caller-state-results-20261108/world-requirements-01.json)
checks all 58 explicit raster/trail/sprite whitelist return sites against pinned
original bytes. [The next analysis](caller-state-results-20261108/world-requirements-02.json)
follows direct callees and separately includes the already guarded enclosing
trail/sprite return contexts. Neither report asserts state equivalence. Later
analyzer/runtime source changes retain those exact historical phases.

`caller_state_liveness.py` uses the installed Capstone-5 register-access ABI.
It keeps per-register bit masks, partial writes, carry-preserving INC/DEC,
conditional writes and unknown calls/returns explicit. It never discards a
volatile register merely because of a calling convention. A closed direct loop
does not assert termination or semantic equivalence. Floating-state and stack
memory effects need separate proof. The local controls include branch splits,
unknown/indirect flows, recursion/work limits, high-byte masks and conditional
destination preservation.

[Pinned entry disassembly](caller-state-results-20261108/world-entry-bodies-01.json)
retains 21 original producer bodies as recovery inputs. Linear decoding does not
recover embedded data or unresolved flows. The generic bodies contain exact
integer FILD/FIMUL/FISTP preparation; ordinary fast pixel bodies contain no local
x87 instructions. Wave/source-row routines also have lazy non-pixel table
initialization. Their outgoing effects must be preserved, rather than assuming
that restoring incoming FX state reproduces the original.
