Task6's ordered feature prefix is encoded in owner_planner_features.hpp. Features
26/84 measure spread within a group and are zero for singleton groups. Feature55
queries current regional danger through the actor or remembered snapshot's owner,
flags and bravery. The five suffix fields are uncertainty radius, three path
summaries and the assigned/probe flag. The uncertainty originates from copied
actor+b63: `(unsigned(tick-seen)*unsigned(b63))/72`, then squared. It is not CFG
movement speed. Probe production is not established by testing supplied summaries.

Brain nodes have twelve floats: location, positive scale and ten bin values.
The scaled bin is truncated toward zero; negative/overflow bins use signed tail
values. Each quadratic accumulation stores to float; exponential reduction uses
the original x87 sequence on x86 and an extended accumulator for normalization.
The score uses coefficient2*probability2 minus coefficient0*probability0, the
pinned double0.999 cap, and the pinned float0.01 percentage transform. Explicit
stores and exact constants matter on i386. Fewer than two positive observation
layers return uniform probabilities. Native validation rejects malformed extents,
nonfinite data, unsafe bin conversion and normalization overflow. Model training,
missing-model recovery and non-x86 numerical equivalence are unvalidated.

A task remembers an anonymous memory key and center, not a host actor pointer.
`407c10` resolves a slot only when the memory's marker equals the current tick.
A stale/missing memory keeps the last center; reaching it at squared distance<10
completes the task. A current marker resolving dead/allied completes immediately.
Engagement, incoming work, readiness and dirty932 suppress order delivery. General
multi-target assignment, risk-stop52a430, formations and other-brain assignments
remain outside the execution projection. Lower target/move calls are explicit
recorders in this comparison; the native application uses the owned command layer.

## Native integration policy

`run-planner` opts into a fixed two-type17-actor lab, moving its initial stands
into the same admitted region. Installed encrypted CFG, ANI, MAP and TTD remain
immutable. The adapter runs after perception/knowledge/danger and before creature
maintenance, with two count units per normal frame. It prepares only a single
remembered hostile in the actor's current region with nonzero region parameter;
multiple anonymous records or other regions yield no candidate. It explicitly
supplies zero path summaries, false assigned flag, coefficients1/0/1 and100 percent.
These are bounded lab policies; no successful original route probe, recovered
coefficient initialization, risk rejection or original World cadence is claimed.
The active task is retained until completion, then selection restarts; original
replacement/replanning deadlines are not implemented. Creature autonomy continues
in the same command pipeline, so an active task frame is not a distinct order.

The native model and logical task/selector state, strategic RNG, owned72 features,
serials and observed actor projections are stored in CMD1v12. Old versions decode
without them and legacy writes reject dropping them. Resume needs neither the
installation nor the PE. Fresh activation is staged, and failed frame inference
must roll back perception, tasks, RNG and command consequences together.
