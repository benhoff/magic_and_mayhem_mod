# Native ANI-driven movement and owned continuation (NS05)

This milestone composes the existing recovered forward ANI controller with the
bounded planar category-zero motion driver. Native v5 owns ANI bytes and controller
continuation. It does not replace live gameplay, implement complete action selection,
handle arbitrary gameplay events or write original version-20 saves.

## Evidence and confidence

Pinned No-CD executable SHA-256:
`40209ca76705b5db04ea1974543bdec1739c68acdebdbefe2537ed025b8b7168`.
The selected action at `0x5104b0` advances the primary controller at `0x464ec0`
for each admitted movement substep. Raw event 2 selects the branch at `0x5108c2`:
restart `0x464d70`, restore residual snapshots (`+b83/+b87`) and sample pointer
(`+b93`), and clear the substep counter (`+b77`). This precedes accumulator
subtraction and the progress-completion check. The restart routine clears
forward display/timers/repeats/break state and starts the already selected sequence,
including initial control dispatch, as modeled by `NoCdAnimationPlayer::start`.
Reverse scanning remains excluded. The event jump table is at `0x510e5c`.

`tests/test-original-ani-motion.py` verifies executable hash and entry anchors,
then runs original action/start/tick/restart together in a disposable i386 mapping.
Only route completion (`0x512460`) is redirected; ANI events are generated by
unmodified original controller bytecode, rather than supplied clock stubs.
The original and native states remain independently advanced between calls.
Between completed segments the harness supplies matching planar consumption/carry
inputs; complete route/setup behavior retains the separate NS04 evidence.

All **28,800 composed action/controller transitions** match: eight directions,
delays 0/1/2, rates 0/60/720, durations 120/720, repeat/no-repeat bytecode, and
100 calls per combination. Checks include completion, motion XYZ/progress/travel,
accumulator, sample cursor, residuals, substep count and controller PC/display,
active, delay, elapsed, repeats and break flag. Confidence is high for these
selected forward event-0/event-2 contracts; it does not establish all action
branches or original global clock ordering.

The existing installed-controller runner was repeated after integration. All
**347 traces / 22,555 states** match (340 selected installed version-5 sequences
plus seven synthetic controls). Owned byte decoding matches all **136 ANI files**,
including the three legacy files supported by the existing loader. Native movement
admits only version-5 profiles in this milestone. Both original experiments verify
all **2,927 immutable input files** before/after and retain input/source hashes.
Historical forward selection coverage is described in
[animation-forward-contract.md](animation-forward-contract.md).

## Native integration and policies

`move-ani MAP ANI BASE OUTPUT SX SY SZ TX TY TZ TICKS` selects eight contiguous
forward sequences at an explicit caller-supplied base, indexed by route direction.
This is a bounded resource-selection policy, not recovery of original type/config
mapping. The app adapter uses the existing byte decoder and recovered controller;
native simulation and persistence contain no Qt, ANI opcodes, original addresses
or reconstruction dependencies. Pure ANI decoding is now separate from AssetFile
loading so the headless adapter can reuse it without a Qt link.

A local owned player is reconstructed/restored and staged for each invocation.
Movement substeps call its actual bytecode controller. Matching segments preserve
controller state; turns/new orders initialize the selected sequence. Event 2
restarts it and resets motion snapshots; unsupported events, including stop result
1, reject the tick before world/controller commitment. Negative sprites, inactive
selected profiles, invalid control transfers/budgets and reads beyond the 48 owned
motion samples are refused. No wall-clock FPS or minimum speed is introduced.
The default `move-fine`/`move-continuous` supplied-clock contracts are retained.
Callbacks in the arithmetic model must mutate only caller-staged state; it cannot
roll back external I/O or arbitrary callback side effects.

The world owns exact original ANI bytes and selected sequence base. Its current
and completed fine records own numeric sequence, next/display indices, active,
delay, elapsed, repeats and break flag. ANI source edits/deletion therefore do not
change continuation. The frozen map still requires its exact external binding.
`MovementSession::restoreResources` resolves against owned saved resources before
committing map/world; the old map-only restore remains available and refuses
incompatible ANI bindings. Ongoing restoration reconstructs segment setup and
replays all saved movement invocations, comparing both arithmetic and controller
fields. Completed history receives bounded profile/extent validation; it is not
an authenticated record of all past ticks. Resource storage/copying is bounded,
without an established real-time performance claim.

## Validation and remaining work

**31 normal and 31 ASan/UBSan CTests** pass, including prior native v1/v2/v3/v4
wire/movement regressions and animation model/placement/attachment checks.
Leak checking remains disabled in the traced sanitizer environment. The new
independent v5 Python oracle checks pending, completed-boundary, intra-cell and
event-reset bytes and resumes a Python-authored checkpoint. Fresh processes agree
for 20 vs 6+14 ticks, boundary/event splits, turning routes, nonzero repeat counters, fractional speed and 80-tick prefix
replanning. Source deletion, unsupported events, malformed checksummed cursors,
wrong sequences and changed maps are covered. A C++ fixture checks failed in-place
resource/replay restoration preserves both world and subsequent tick behavior.
The controller's new owned `restore` validates before changing state.
ANI and legacy ANI/SPR loader fixture tests also pass after separating decoding.

in [native-ani-motion.json](native-ani-motion.json). The wire contract is documented
