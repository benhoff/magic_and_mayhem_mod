# Separate cursor-source gate diagnostic module

Opt-in native diagnostic PE32 module. It verifies NoCD base, exact constructor/
close-call byte anchors and original IAT cells before installing Create/Close
wrappers. Original calls forward once. Only exact observed constructor returns
with null security/name/unowned creation publish private duplicate identities.
Publication reservation prevents simultaneous duplicate work per role. Original
close entry retires identities; private duplicates stay live through active tokens.

Versioned128byte begin/end outputs contain numeric owner/token/identities/raw
wait/release/failure/stored-level scalars, no handles or host layouts. Begin checks
current-thread/output and pinned globals against tracked identities, reserves
lifetime refs under the lock, then waits outer0/inner0 outside it. End releases
stored levels outside the lock and drains only after successful release. Both
preserve LastError and full512FX. Invalid output refuses unchanged.

This intentionally changes timing and duplicate object lifetime. No source
capture integration, durable diagnostic journal, full orphan/fault disposition,
explicit bounded shutdown or worker callback controls exist yet. Loader-lock
shutdown performs no blocking lease cleanup. Unknown lifecycle/refusal remains
open, no unobtrusive/live replacement/reference/parity claim.
