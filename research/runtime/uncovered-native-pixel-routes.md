This work addresses the 24 routes absent from the retained six-family native
camera, spell and storage journeys. It keeps original caller reachability,
isolated production-splice comparison and native live execution independent.
No route is removed from the 43-route denominator.

`tools/test-uncovered-pixel-routes.py` runs the actual pixel, minimap, colour
rectangle and raster production-splice comparisons against the pinned NoCD
original. Each result must identify every interior route and contain native
execution with a physical pixel change in both RGB565 and RGB555. The comparison
checks the complete physical output and the fixture's stated caller contract
before counting a call. This prevents an entry aggregate, a no-op admission or
original forwarding from standing in for native drawing on a missing branch.
Rectangle modes 0 through 3 have separate checks in both formats.

The fixtures retain original wrappers/preparation with supplied Win32 and
owned-plane adapters. Their inputs are bounded authored fixtures, not newly
observed game callers. Camera3 is called explicitly in its isolated original
fixture; the original live camera table is unchanged. World batching continues
to bypass selected CPU interiors. Fresh comparison does not establish live
reachability, arbitrary CPU history coherence, original driver behavior, complete
session presentation or sustained performance.

```sh

  --behavior NP.uncovered-pixel-route-matrix \
  --behavior RS.image-effect-pixel-state --behavior RS.minimap-pixel-passes \
  --behavior RS.colour-rectangle-pixels --behavior RS.outside-world-raster-pixels \
  --behavior RS.colour-rectangle-empty --output working/route-claims-next.json

  python3 -B tools/test-uncovered-pixel-routes.py \
  --claims working/route-claims-next.json --report working/route-result-next.json
```
