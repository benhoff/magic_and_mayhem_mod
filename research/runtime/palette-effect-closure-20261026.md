# Palette effect completion and acceptance

This batch reconciles the broad RE.palette-effect-builders parent with the existing
ten numerical modes, owned chains, raw profile/allocator providers and native
resource/pixel delivery. The native implementation milestone and the original
platform/exceptional-domain and whole-game acceptance boundaries remain independent.

The new fixture records actual PE32 Wine current-directory and profile calls for
installed configuration and missing/empty/quoted/nonnumeric/truncated inputs. It
replays only those external service results into unchanged original builders.
Original tables and source mutations are comparison output only. Independently
loaded owned SPR palettes feed native chains and resource/software-GL rendering.
Three installed creature palettes are presented as an authored all-index atlas;
this is installed-derived palette coverage, not an original gameplay journey.

The full raw ownership/provider matrix retains allocation-failure and partial-chain
observations, while native append failure remains deliberately atomic. Unsafe odd
original allocations are not emulated; complete native storage and finite profile
admission are explicit policies. Windows SEH, exceptional CRT continuations, actual
legacy drivers and complete live-game replacement remain outside this packet.

Results and exact unique inputs/binaries are retained in SQLite.
