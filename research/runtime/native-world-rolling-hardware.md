# Native World on NVIDIA EGL

Run `python3 tools/test-native-world-rolling-hardware.py --corpus <saved-resource-reuse-run>`. The runner freezes and verifies both the World consumer and the existing EGL platform plugin, checks actual compiler dependencies and binary hashes, selects the NVIDIA EGL device/vendor and refuses a software fallback. It runs512 source-only queues:32 saved queues with1224 checkpoint digests followed by480 synthetic continuations with eight changed-coordinate requests. Every native CPU/GPU completion and ordered acknowledgement must agree; caches and teardown remain bounded. Five Debug fixtures run separately on software Xvfb, not on the hardware device.

Unchanged predeclared budgets: continuation consumer completion median60/p95120/max300ms, first completion500ms excluding saved hash assertion time, retained growth32MiB after queue64. This is hardware native rendering completion and packet ownership evidence. It does not measure original game simulation, Qt widgets/paint, a compositor, monitor, input-to-screen latency or live producer hardware integration. The private NVIDIA device avoids user desktop interaction; existing Xorg authorization is unavailable to this session.

The [frozen NVIDIA result](native-world-rolling-hardware-nvidia-20261010.json) passes all512 queues:27.55ms continuation median/35.49ms p95/49.82ms maximum,251.82ms cold completion and1.5MiB retained growth.512 independent native CPU/GPU completions and ordered acknowledgements,1224 saved hashes, eight changed requests, packet/cache bounds and zero teardown surfaces pass. All five Debug fixtures pass separately on software Xvfb. Both optimized consumer and freshly built EGL plugin compiler closures and binary hashes verify; there is no software fallback.
