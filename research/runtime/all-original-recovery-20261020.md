## Confirmed behavior and ownership

**Finalizer and font writes.** Global `0x6e1f1c` governs PageLock; it is distinct
from the background flag at `0x6de6dd`. Original `58b660` can Unlock and still
return its pixel pointer. The finalizer/font path then writes through that
pointer, and the outer caller subsequently Unlocks again without checking the
failure. This observed original lifetime is not silently replaced by a native
lease policy.

**Pool ownership.** The 1,792-slot manager admits high-priority full-pool
insertions through its hint gate and selects a strictly lower-priority victim.
The hint becomes the selected index minus one. Reverse updates reread the slot
after callbacks, so nested insertion/eviction and swap-with-current-last depend
on the current count. A rejected insertion does not destroy the caller's object.

**Real backing generations.** Later Surface3/4/7 aliases and held Lock/DC access
survive the original wrapper/registry retirement. Transparent, signature-checked
provider IAT observation associates each 96-byte pixel span with a distinct
`calloc(1,112)` generation and its completed free. Same numeric addresses on
reuse receive new generations. A missing free exit or an expired span cannot
resurrect a generation. This is CPU provider storage evidence, not an inventory
of every allocation family, external CPU writer, GPU object or kernel object.

**Concrete class families.** Sixteen assigned core tables contain thirteen
concrete classes and three abstract parent tables. The recovered constructor,
updater, property and draw families are independent contracts: exact table
identity does not alone recover a method. Ordinary and cached colour classes,
additive/owner classes, nonraster emitters, owner emitters, flag emitters, seekers,
attached sprite classes and fading sprites now have executed scoped coverage.
Private MSVC SEH chains allow unchanged constructors to run in isolated i386
fixtures; this does not test exception unwinding.

**Original quirks retained.** Seeking Z steering compares target X against old Z;
its denominator still uses the raw wrapped signed Z difference. Attached
constructors use the horizontal owner offset for Z, while updates use the
vertical offset. Owner emission at `547380` propagates only X/Y follow flags and
offsets, preserving constructed Z state. RGB555 half blending uses the effective
`0x7def` mask, including the incoming unused high bit. These are recovered
baseline details, not balance changes.

**Terrain lifetime.** Cached particles retain their cell pointer and shade
across global cell/shade rebinding; edits through the retained cell/descriptor
remain visible. Coarse shade Z indexing differs from fine collision indexing.
For block zero on a cache miss without collision, original `548860` never
initializes its descriptor scratch before writing `+0x42`. The native model
exposes descriptor validity, comparisons exclude those four undefined bytes,
and the original raw values remain retained. External terrain/descriptor owners
and reclamation are still unresolved.

**Mutable traversal.** Original World consumption snapshots some inputs and
rereads others after callbacks: entry backing and hardware path are retained,
while count, later rows, clip/padding/tall-video settings and finalizer facts can
change. Kind 9 clears its metadata before the helper and preserves callback
writes. The supplied mutable model reflects those orderings; it does not assign
defined behavior to original invalid pointers or freed storage.

**Special raster effects.** `57e8e0` selects two copy frames or four 75/50/25
frames and ORs AX results. `57fe10` draws encoded run endpoints when horizontally
unclipped, but half blends visible pixels when clipped. `581200` writes tint
borders, including positions before a run's logical beginning, when unclipped;
the clipped branch uses palette-zero half blend. `580260` displaces destination
writes, whereas the separately recovered wave helper reads displaced pixels.
It initializes its lazy sine table before empty/offscreen returns. Assembly
initializes the row counter despite misleading decompiler output. Both selected
CPU WORD providers perform raw WORD copy.

**Seed context.** Particle seeding occurs at `4bec0a` with constant `0x499602d2`,
and at `4e4484` / `55780e` from `timeGetTime`. The six global R250 receivers are
independent state arrays; every seed operation uses shared LCG workspace
`0x6f2a9c`. Reseeding another receiver changes that workspace without resetting
particle words. The comparison executes original caller slices with only their
relative seed CALL operand relocated and a RET appended; it does not claim
whole caller execution or a real live clock.

**Factory and publication.** `549e80` skips categories 0/24/25/26, prepares the
two fallback resources and the selected category, takes the larger piece/vector
count, consumes 28-byte velocity records backwards, then generates fallback
velocities. Allocation failure still consumes the velocity RNG; successful
objects consume their constructor RNG. A refused pool transfer invokes the real
deleting destructor. Successful lazy resource preparation divides frame count
by nine and requests palettes in order 1/2/6/4/5/7; failure preserves prior
counts. File parsing and the actual loader remain separate. `545990` visits
particles backwards, checks visibility using an upper-clamped Z cell, projects
through all four camera orientations, tests class width/height, and publishes
kind-8 rows. Queue attempts increment even when full, and the final row DWORD
is untouched. The complete actual producer/helper composition matches native
records on the declared stable-owner domain.

**Alternate copy.** `594508` reads from `0x6e1f6c`, not the enable global
`0x6e1f68`. It reads four WORDs before either DWORD store, advances destination
contiguously, and advances source by pitch plus four times horizontal padding in
bytes. Overlap therefore follows forward chunk ordering rather than memmove.
The helper's original positive-height/four-WORD-width preconditions remain
explicit. Its native model preflights owned extents before mutation.
