## Changes and Cancel semantics

Physical setup input changes starting mana, lives and the human player's handicap.
Opening the map chooser observes those changed values in the original setup
payload. A different map selected and confirmed changes the original map identity
and name while preserving the current rules and players.

Cancelling the map chooser instead preserves the complete current setup,
including changed rules/handicap and the previous map. Cancelling the outer setup
discards that draft: reopening Create Single Player restores the entry defaults.
The original recreates AI names and portraits on fresh setup entry; these cosmetic
fields are retained as observations, rather than asserted as persistent identities.
Human fields, map/rules and the remaining AI configuration fields are still
checked. Quick/Setup focus is observed directly after each relevant return.

The native paper-menu layout, focus treatment and physical input behavior are an
intentional native UI policy. The retained screenshots are reviewed as native UI
captures; this work does **not** claim equality with original menu pixels.
Some transition captures precede the native repaint and show a blank viewport.
Those images remain retained and cannot satisfy the visual guard. Each context
must also have a retained ready Main capture with the focused control visibly
painted. Accessibility readiness and physical effects are separate observations;
simultaneous painting at every transition is not asserted.
