Important observed details:

- A free-slot lookup does not reserve the slot. Traversal rereads cursor/backing
  after a predicate callback; capacity, active flag and high-water are distinct.
- Follow repair at `+906` is unconditional on a match. Primary/alternate repair
  additionally uses health at `+e4`. The type-5 special condition is captured
  before callbacks, while subsequent action/task fields are reread.
- Map lookup tables `6cb942` and `6cb8c2` contain DWORD entries. Wide detach's
  first two columns conditionally clear a matching occupant and restore terrain
  flags; the last two unconditionally clear occupant/bits without restoration.
- The ordinary leader classifier accepts exactly types 0, 24, 25 and 26.
  Release, cleanup, active flag, health gate, slot reset and backing destruction
  are distinct operations. Repeated release is not an idempotence guarantee.
- Animation descriptor stride is `0x114`. Baseline binds the embedded object at
  `+825`; initial activation binds `+b0`. Preload is a low-byte flag, including
  `0x100` behaving as zero. An owned load failure invokes UI providers and
  continues; it is not a recovered safe activation refusal. Positive map
  extents are an explicit precondition; original zero extents can loop.

## Corrected legacy driver diagnosis

The user confirmed no Windows 98/ME host is available. The supplied native DirectX6
runtime plus hash-pinned DIB Engine still fails `LoadLibrary` with error 998 on
Wine 11.16, before a legacy offscreen surface is available. Builtin DirectDraw
fallback remains disabled, the X server survives, and original DLL instructions
are unchanged.

The earlier REC10 statement identifying DIBENG's `INT 31h` calls as the terminal
failure was too strong. A bounded trace shows dispatch of Get Descriptor (`000b`)
and Set Descriptor (`000c`), followed by continued execution and a later 32-bit
access violation. A read-only first-chance observer records the actual later PC,
access and `VirtualQuery` result and always returns `CONTINUE_SEARCH`; it never
changes protection or handles the exception. In the final run the write targets
committed read-only mapped memory. Runtime addresses and the exact later fault
vary with diagnostic configuration; they are not stable cross-run identities.

The static parser now correlates the observer only with the matching later PC.
Six independently authored NE/trace tests cover extent refusal, register parsing
and the distinction between mapped descriptor instructions and terminal-cause
proof. Wine source also contains descriptor-service handlers; that source alone
is not proof about an installed binary's correctness. No specific compatibility
fix, physical legacy driver result, or successful original-wrapper admission
is claimed. See [the NE format note](../formats/legacy-ne-dibeng.md).
