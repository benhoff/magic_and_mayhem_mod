Results Continue/exit, Quick, Main and normal Quit. Storage cases bind restored
Campaign World, the acknowledged menu/return route, Main and normal Quit. The
original owner thread and ACK order are checked within each individual session;
thread/address stability across launches is not assumed. Forced termination,
fallback, recovery, an incomplete menu route or an abnormal original exit cannot
close this claim. Escape Results does not establish natural victory or defeat.

Each final actual swapped World is joined to its retained command sequence and
the accepted independent complete-output comparison. Eight final presentations
reuse **7,486,400 pixels**, with zero mismatches. The reference derives from
continuous owned original history, without native-player or original destination
pixels as its oracle. These pixels were already compared; they are not a new
comparison count. Swap multiplicity is retained. A final imported source may be
coalesced rather than swapped; every imported source still has to retire.

## Imported source and shutdown ownership

All **3,713 imported World generations** are bound to an actual command surface
incarnation, identified by surface ID and CREATE sequence. Each import follows
that CREATE and precedes its matching DELETE, which must precede command END.
The final swapped presentation's output surface has the same ordering check.
This handles reuse without assuming an ID denotes the same lifetime forever.
The full existing surface/palette count and logical-byte resource ledger is
rederived and must equal the accepted ledger exactly.

The original V6 source channel exposes a deliberate normal-stop boundary:

- Completed imports, original returns and independent history generations agree.
- The next unsubmitted generation is original-owned `WRITING`; the other slot is
  `FREE` for the last completed generation. No native-owned request, processing,
  reply, returned or source-chunk slot survives.
- `canvas_producers_close` records terminal reason 1 before cancellation. The
  retained channel has `cancelled=1`, `finished=0`; cancellation is not relabeled
  as successful finite-cap completion. Other terminal diagnostics are rejected.
- The terminal record's next generation and owner thread match the imported
  session. Its caller address is retained, rather than assumed stable.

Both slot headers, channel nonce and protocol identities are checked directly.
Attached role bits remain in the historical channel; they are not used as a live
process count. Independent command/control records must prove drained command
END and acknowledged original producer Stop. The existing terminal cleanup
decoder additionally proves inactive released input, no cursor clients/jobs,
returned source work, zero pre-reclamation graphics owners, renderer retirement,
original exit 0 and a stopped private prefix. Process exit alone is insufficient.

The claims concern normal terminal World shutdown and its retained protocol
owners. They do not assert immediate deletion of every cached/external API object
at each intermediate menu transition, physical VRAM measurements, or an OS-wide
handle census. Natural later-map transitions retain their own outstanding rows.
