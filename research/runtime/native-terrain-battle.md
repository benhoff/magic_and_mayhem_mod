# Installed terrain in the shared native battle

The first binding projects Plains `CPsec01.map` through the existing ordinary
terrain initializer, then crops source `(4,4)` to12x12 across all source layers.
Source runtime references and static objects are omitted. The outer XY ring is
sealed. Installed type17 Crocodile CFG dimensions/acceleration/swimming and ANI
movement samples replace the diagnostic frozen profile. This is a native policy;
it does not extend the original whole-search or map-entity equivalence claims.

`MNMTER01` owns a canonical bounded JSON payload: exact source MAP/TTD/CFG/ANI
SHA-256 values, fixed source requests/crop, base64 frozen terrain/profile bytes,
selected standing layer and two wizard origins. Rebinding validates canonical
encoding, frozen dimensions/profile, legal same-plane origins and separation.
No installation path, legacy pointer or writable original is retained.

The deterministic selection chooses the layer with most legal2x2 origins and a
maximally separated connected pair. All battlefield actors reserve the same
installed2x2x2 profile, including the authored stationary wizard placeholders.
This is an explicit native wizard placement policy, not a recovered wizard type.
Routing is bounded same-plane BFS over recovered ordinary neighbor legality;
occupancy and movement reservations use the existing full-profile native adapter.
Layer transitions, original full-world search/cadence and runtime map objects are
outside this encounter.

The binding regression checks installed movement and restoration at each boundary,
sealed/unsupported cells, overlapping-spawn rollback and malformed bundle refusal.
The initial binding commit claimed no shared combat integration. The next native
combat driver extension owns `CRB2` terrain continuation and uses the same
installed footprint/neighbor legality for orders, pursuit, melee and restored
state.100 direct/fresh combat continuations agree in the development check.
Combat accepts a large navigation footprint only with an explicit driver.
Skirmish campaign/spell/window integration remains a separate next chunk.
No original comparison or original movement-speed equivalence is inferred.

Terrain movement CFG/ANI hashes must equal the actual raw inputs embedded in
the owned melee profile, both at installed construction and snapshot resolution.
A mixed profile refuses; this also prevents separate installation reads from
publishing mismatched movement and melee configuration. HTH stays profile-owned.
