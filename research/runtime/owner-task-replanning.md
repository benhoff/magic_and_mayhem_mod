## Previous-task admission and replacement

Whole4284e0 gates each unbiassed candidate against a supplied previous task before
applying bias, exact-one rejection, maximum/weighted selection and tie RNG. No
previous task, or previous completed byte+15, bypasses the replacement gate.
A weighted previous task (+1a) admits only an exact candidate1. Otherwise:

```
denominator = 1 - candidate * previousValue
improved = denominator > 0 &&
           (candidate - previousValue) / denominator > improvementThreshold
```

The comparison is strict. The pinned default threshold5d8654 is binary32
0.8999999761581421. If improvement fails and previousValue<1, the fallback is:

```
progress = ((baseline + epsilon) * (successes + 1) / (attempts + 1)) /
           (currentOwnerRatio + epsilon)
elapsedFraction = (clock - started) / (expires - started)
replace = pow(progress, elapsedFraction) < expiryThreshold && candidate > 0
```

The base is **progress**, with elapsedFraction as exponent. The x87 stack order
and wrapper59bcc0 establish this; the direct original comparisons distinguish
reversing them.40a3b0 obtains currentOwnerRatio from owner922/(926+1), or zero
when that owner is unavailable. Baseline is the binary32 value captured at task
installation. Successes/attempts are task+2f/+33, not distances or route counters.
Their broad event producers remain unresolved. Epsilon5c5378 is pinned binary64
0.001, and expiry threshold5d8658 is binary32 0.0010000000474974513. Original
arithmetic uses extended intermediates, then the pow wrapper stores both
operands to binary64. Native comparisons preserve those stores; no claim of full
CRT pow result bit equivalence or non-x86 numerical equivalence is made.
