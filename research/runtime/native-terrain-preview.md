# Bounded native terrain preview

`apps/terrain-preview` loads installed owned TTD and SPR assets and uses the
[selected recovered producer](terrain-submission.md), original queue ordering
and optional visibility reconstruction. Definition/view supplies actual frame
selection; no synthetic ANI, original game session, Wine or runtime hook is
involved. The application service orchestrates storage/reconstruction/rendering;
the Qt widget only presents the completed image.

## Validation

[Machine-readable normal/sanitized evidence](native-terrain-preview.json)
records 32 complete installed frames in each build: four orientations, separated
and common anchors, visibility disabled/enabled, and distinct/repeated terrain
definitions. Each matches original producer/sorter/reverse-pass output for tile,
frame, role, anchor, key, kind, shade and both owner flag WORDs. Independent
Python SPR decoding and composition matches all 131,072 RGB565 pixels and
512x256 presented RGBA hashes. Four real overlap cases hide seven draws each:
28 hidden decisions per build. Surface count returns to zero after every frame.

Normal artifacts: `working/tests/terrain-preview/run-sgky3a_u/`.
ASan/UBSan artifacts: `working/tests/terrain-preview/run-swneovdz/`.
Both original manifests passed before and after each run. Inputs, helper/oracle,
native binaries and implementation files are hashed; source changes during a
run are rejected. LeakSanitizer is disabled for managed execution; explicit GL
resource accounting is checked, and prebuilt Qt/driver libraries are not
instrumented. Owned catalog/malformed extent tests also pass in both builds.

The installed Celtic Forest catalog has no nonzero first/second layer arrays.
Those producer branches and their flag changes are covered by original/native
synthetic comparisons, while installed Qt comparisons here exercise body draws.
Native role identity uses owned source offsets to preserve encoded-frame aliases
without retaining original pointers. The 32 reference queues are generated by
the unchanged original function, with the recovered 43-byte visibility stride
and an initially empty 14,577-byte grid explicitly initialized.

## Bounds and remaining work

Preview policy is explicit: 1..9 definitions, raw view 0..3, a 512x256 canvas,
three-column diamond or common anchors, zero height/base priority/light and clear
initial owner flags. There is no world map, simulation, camera or animation
clock. Out-of-canvas sprite draws are rejected; this is not original clipping.
Original shading is recorded but images use unshaded embedded palettes.

Remaining work includes actual MAP tile decoding/traversal and upstream
screen-anchor/priority production, lighting/palette chains, water/overlays and
object/creature terrain paths, visibility activation and live replacement.
This milestone establishes a direct native installed-asset rendering path and
keeps those broader claims separate in AS04/GP08 of the coverage ledger.
