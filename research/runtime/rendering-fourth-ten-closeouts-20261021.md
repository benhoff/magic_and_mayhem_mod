The combined runner is `tools/test-rendering-fourth-ten.py`. It declares behavior
and scenario contracts before execution, pins both production build closures,
checks actual fixture compiler dependency files and source stability, and writes
its immutable result directly to SQLite. Optimized and ASan/UBSan executions
cover the host lifetime/token/lease and recorder models. PE32 fixtures execute
against Wine 11.16 kernel APIs in one explicitly owned, locked reusable prefix.
No original artifacts or game process are consumed by this batch. Production
scene and drawing observers are compiled; their game installation is excluded.

The new cross-role rejection is intentional native ownership policy: a role
must own its private duplicate independently. Distinct handles that happen to
refer to the same kernel object remain allowed. An unavailable release callback
cannot turn retained levels into a successful release. Decoder hardening admits
only journal fields that the bounded emitters can produce; reason 8 explicitly
retains an invalid phase scalar because that is the guard being diagnosed.
Buffer lookup retains unknown generation zero and consults the exact recorded
entry/return lifetime prefixes, using linear transition storage and logarithmic
lookup rather than snapshots of all objects at every row.

Historical evidence retains its exact hashes. Changes to shared helpers and
fixtures make some earlier results stale; this execution renews only these ten
implementation scopes. Existing understanding/comparison/integration/replacement
statuses are retained. Original callback/worker order, unobserved Wine aliases,
actual intermittent source race reproduction, physical hardware, source pixels
and full DRAW-02 acceptance remain pending.
