# Bounded Magic Sphere motion comparison

The type3/spell73 path through No-CD `004883f0` is compared using 128 authored
worlds and sixteen repeated calls per world (2048 calls per implementation).
Iteration counts cover 1..20. The comparison preserves guarded original records,
cells, actors, catalogs and cleanup columns; it checks creator exclusion, ordered
candidate collection, type3 hit retention, changed cells, wrap and selected
bitmap/blocked/height branches. Actor worlds stay fixed within each fixture.

Native admission now permits spell73 and bounded continuation counters/iteration
counts sufficient for the native battle adapter. This is an admission extension;
the compared domain is the authored fixtures, not every permitted counter value.
Other effect types, original ricochet geometry, full projectile creation, installed
profiles and live replacement remain separate. Confidence is high only within
the recorded comparison domain. `tools/test-projectile-motion.py` requires the
pinned No-CD executable hash and verifies original manifests before and after.
Execution results are registered separately; this document is not proof of a run.
