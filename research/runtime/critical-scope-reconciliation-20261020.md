# Nine Critical rendering scope decisions

This review closes the scope-decision work for the nine Critical contracts that
were grouped as reconcile/extend. It does not certify their complete original
functions, physical ownership or all-game rendering. Existing behavior IDs,
unknown branches, original address links, stage history and execution hashes are
retained. Scope resolution and fresh bounded execution are separate results.

The isolated source baseline is `f0c4e03a`. Other contributors were merging the
shared checkout, so execution uses its own registered worktree. Retained capture
and installed-asset bytes remain read-only; local report copies change only the
experiment path, with the original report path/hash recorded in relocation
provenance. The native code never receives original destination oracle images.

## Reproducible bounded execution

`tools/test-critical-scope-reconciliation.py` prepares source/contract/scenario
declarations before building or executing. It runs four native controls, actual
PE32 startup-hook forwarding/refusals, the unchanged-original branch matrix,
768 full original/CPU/GPU wave comparisons, default producer replay, sixteen
zero-policy startup completions and source-only finite GPU handoff. It requires
all three startup match fields and nonempty exact checkpoint denominators.
Original manifest verification brackets execution, and each component retains
its existing preservation checks. Fresh reports receive new evidence IDs;
historical execution hashes and earlier failed results are not rewritten.

Physical allocation, real driver recovery, unsampled writer/caller routes,
complete live bypass and whole-game/hardware acceptance are not execution
outcomes of this coordinator. Their explicit required cases and closure
conditions remain visible in the UI planning assessments.

## Executed result and independent milestones

All nine bounded runs pass on the declared isolated sources. Palette selection
now covers 14,280 cases / 3,655,680 words. Default producer and GPU handoff each
match all 1,061 checkpoints / 474,235,312 pixels. All 16 startup completions and
all 16 independent handoff World completions match, and all 768 CPU/GPU wave
canvases match. Four native controls and the actual PE32 startup hooks pass.
The supplemental producer fixture passes 57 forwarding sites, 13 complete raster
bypasses and caller/ABI/refusal controls on a fresh private prefix. Its first
attempt lost the private Wine-server connection; that setup failure and the
distinct successful retry are retained without relabeling the failure.

Only the three intentional native policies gain scoped implementation and
headless integration; all six recovered-original contracts retain partial
implementation, their original comparison/replacement stages and wider gaps.
The nine scope decisions are complete. Three now have concrete original recovery
next work, and six retain wider supported-session acceptance. Completed native
contracts remain visible separately from the Critical partial denominator.
