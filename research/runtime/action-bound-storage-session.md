# Action-bound storage session comparison

## Contract and current evidence

The bounded reference is original-active Apprentice campaign entry, Save, Load,
return to Main, High → Low → High display rebuilds, Main Load, resumed World,
and normal Quit. Only recovered callbacks and ordinary XTest input drive the
original. Save uses a fresh ASCII stem in the isolated installation's required
`Save` directory; Load must enumerate exactly that stem and preserve its bytes.
Every World checkpoint requires at least three newly returned source queues.

Original pixels remain comparator-only. Each observed successful EGL swap has
an independent fenced full RGBA witness, two stable captures, exact call and
worker/submission identities, and atomic original callback epoch snapshots
before and after the original swap. Epochs are journal identities, not proof
that a particular input caused a source change. In-flight or changing epochs
remain ambiguous. These observations do not establish all global display routes.
The diagnostic interval closes on returned Main before the original Quit;
normal Quit is corroborated separately by callback/engine cadence completion.

The replay receives encoded assets and scrubbed source-only producer records,
then native-derived snapshots and an input-only GPU composition plan. It receives
no original destination pixels. Native Qt menus follow their declared product
layout/semantic policy; replaying the original layout is not Qt menu parity.
Generic `presented_frame` acceptance and the fourteen-journey/twenty-one-operation
denominator remain unchanged.

`tools/check-recorded-drawing-session.py --catalog
 tests/fixtures/drawing-storage-session/session.json --native
 <build>/composition/mnm-drawing-session-replay --presenter
 <build>/mnm-drawing-present --headless --report <new-report.json>`.
Use the main checkout's storage guard for builds/replays and a writable canonical
`TMPDIR`. A mismatching result returns nonzero while retaining its full report.

pixel differences after driver-order normalization. The old default323frame catalog remains a passing regression.

 tests/fixtures/drawing-journeys/storage-suite.json` with both recorded executable
