# Raster pixels outside protected World batches

Production interior splices retain original source palette, clipping/coordinate and x87/lazy-wave preparation, and native C generates canonical admitted RLE pixels on current owned CPU planes. Families include generic indexed/direct WORD, black silhouette, three destination blends, displacement, projected shadow and grayscale. The two-pass kernel checks every source run and destination/sample address before writing. Malformed/alias/unsupported geometry or palette tables and other threads forward before native stores.

The original footers retain nonvolatile registers and WORD results. Private fast/slow volatile ECX/EDX/upper EAX and scratch argument mutations are outside the declared ABI contract. Generic workspace writes are separately modeled. The bounded original fixture
executes every one of17 entries natively, including clipped/interior rows and
both formats. Initial comparison records8,055 native calls,4,167 full workspace
checks and63,626,240 physical WORDs; larger129/255-column cases, nonzero high
DWORD palette halves and atomic refusal checks extend the final fixture.
Live integration remains pending. This does not retire original preparation, wrappers or simulation, or read back GPU World history.

Recovered details: DWORD-palette copies preserve paired OR of the first
palette entry’s high WORD into the second output WORD, with original scalar leading
alignment/odd tail and nonscalar odd leading WORD handling. WORD displacement increments its phase once
per row, using original anchorY and source-row skip; fast indexed displacement
uses its retained original sine table, or a triangular table when horizontally
clipped. That clipped branch skips certain complete opaque runs reaching or
crossing the right edge rather than cropping them. Grayscale averages the three
five-bit channel units; horizontally clipped grayscale takes the original raw
WORD-copy branch. Generic indexed/black bodies admit widths through255 because
their original byte-register run decoding retains upper width bits beyond that
range. Nonzero original diagnostic clipping validation in fast/slow raster
bodies forwards; direct WORD DF-set string-copy paths also forward. Unsupported inputs forward; this is a scope boundary, not an assertion
of original malformed-input safety.
