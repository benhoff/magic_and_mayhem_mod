Original `004c5520` loads the first active primary wizard via `005908e0`.
Instructions `004c557d..004c55c5` read its nullable knowledge table at wizard
`+0x936` (`0065bb86` for slot0),indexed chapter*124+section. Null means level0;
`006e1f20==1` overrides level4. Original catalog chapter stride is `0x1fc`;
entries have stable ID at+4 and five text-level pointers at+12..28.
The adapter bounds knowledge to0..4 and chooses the nearest lower stored level.
These mappings are build-specific; raw derived disassembly is retained under
`working/decompiled/grimoire-controls-lnth2ma6/original.asm`. Headless evidence `UI64.campaign-grimoire` records162 original knowledge
window/getter cases,13 private caller/dispatcher cases,11 refusals,10 Qt cases,
four regressions and PE32/Qt builds in `campaign-grimoire-20261012.json`.

availability/level table. No host pointers cross the wire. Native code excludes
bounded original text containing dynamic `~D` or another `~NP` page. The native
catalog independently requires a single page without dynamic labels at that

packed section IDs through `004c77c0`;this navigation order is native policy,
not original pagination-helper equivalence. The native display waits for an
engine-confirmed section/level. Original Close3999 runs fade/cleanup and a fresh
original caller restores ownership. ACK sequence and thread are checked.
Older versions retain the six Intro/current-Forest destinations unchanged.

knowledge getter/window executes with an expected-byte-checked endpoint return;
